# Objetivo geral, expectativas e percepção dos resultados

## Objetivo geral

O objetivo geral do projeto é aplicar conceitos de Engenharia de Dados na organização, tratamento e análise da base StudentsPerformance, utilizando a arquitetura Medalhão. A partir dessa estrutura, busca-se transformar os dados brutos em informações confiáveis e organizadas, permitindo analisar o desempenho dos estudantes nas avaliações de matemática, leitura e escrita, considerando diferentes características presentes na base, como gênero, escolaridade dos pais ou responsáveis, tipo de alimentação e realização de curso de preparação.

## Expectativas diante das análises

Espera-se que as análises permitam identificar padrões e diferenças de desempenho entre os grupos analisados, proporcionando uma visão mais estruturada sobre o comportamento dos resultados acadêmicos. A comparação entre as diferentes dimensões pode evidenciar associações relevantes e contribuir para uma melhor compreensão dos dados.

Também se espera demonstrar, na prática, a importância de um processo adequado de Engenharia de Dados. A utilização das camadas Bronze, Silver e Gold permite organizar o fluxo desde a ingestão e tratamento até a disponibilização dos dados para análise, tornando os resultados mais consistentes, rastreáveis e fáceis de interpretar.

É importante destacar que os resultados possuem caráter descritivo. As diferenças observadas entre os grupos representam associações identificadas na base analisada e não permitem, isoladamente, estabelecer relações de causa e efeito.

## Percepção pessoal

Como percepção pessoal, o desenvolvimento do projeto demonstra que a qualidade da análise está diretamente relacionada à qualidade do processo de preparação dos dados. A organização dos dados em diferentes camadas permite perceber que a análise não começa na construção dos gráficos ou nas consultas SQL, mas desde a forma como os dados são ingeridos, tratados, validados e estruturados.

Além disso, os resultados mostram que uma mesma base pode revelar diferentes perspectivas quando analisada sob dimensões distintas. Dessa forma, o projeto contribui para compreender a Engenharia de Dados não apenas como um processo técnico de armazenamento e transformação, mas como uma etapa fundamental para transformar dados brutos em informações confiáveis, interpretáveis e úteis para apoiar análises e decisões.
